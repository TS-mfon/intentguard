## ATM card download and sharing
Public endpoint GET /api/v1/explorer/agents/{id}/card returns JSON:
{agent:{id,name,mission,address,owner,policyHash,chainId,token,status,reviewerAddress,createdAt,...},usage:{requestCount,paidCount,blockedCount,rejectedCount,needsEvidenceCount,cancelledCount,activeCount,fundsMoved,token,chainId,asOf},shareUrl}.
GET same path ending .svg returns standalone attachment with real measured totals (served by root).
Integrate CardDownload component on owner agent overview (after creation link to overview) and public agent explorer. Fetch actual JSON on demand; download SVG directly; offer PNG export using SVG→canvas at 1200×760, revoke object URLs; surface export failures. Share on X uses intent tweet and public agent URL; explain downloading then attaching is a manual action because X composer cannot attach binary via URL. Never expose API keys, owner session tokens, invoices, or evidence in card. Identity generated from immutable id, not fake avatar persons.
Stats are cumulative admitted request documents, PAID amount only (exact units); a generated timestamp makes snapshots honest. Distinguish live balances versus cumulative moved amount. Symbol from runtime config.
