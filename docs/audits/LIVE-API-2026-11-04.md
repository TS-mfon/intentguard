## Re-run the verification

Use Node 24 and the repository's pnpm version:

```sh
pnpm install --frozen-lockfile
pnpm exec tsx scripts/verify-live-api-audit.ts
```

The verifier needs **no API key** for public records, immutable merchant invoices, GenLayer decisions, vault state and token receipts. It checks all four purchase outcomes, the ten captured HTTP checks, exact request/evidence commitments, and the current vault's destination restriction. Captured HTTP failures are historical observations; public verification does not reissue those calls. It prints `LIVE_API_AUDIT_VERIFIED` only after the assertions pass.

To additionally exercise authentication and idempotent replay, supply an active key for this **same card** through `INTENTGUARD_API_KEY` in your private runtime, then run:

```sh
pnpm exec tsx scripts/verify-live-api-audit.ts --replay
```

Replay first verifies the existing private PAID request and its exact input, then repeats that input with its original idempotency key. It asserts the original PAID operation ID is returned. It does not create a fresh purchase. The script prints neither the key nor authentication headers. Credentials and private environment files are excluded from the published evidence.
